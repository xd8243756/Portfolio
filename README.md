markdown# 燐的繪圖小窩 🎨

個人插畫作品集網站，展示日系插圖創作，風格以和風要素為主。

## 📁 專案結構
Portfolio

├── demo.html       # 主要網頁（入口點）

├── mystyle.css     # 樣式設定

├── javascript.js   # 網頁互動邏輯

├── artInfo.json    # 作品資訊資料

├── art/            # 插圖圖片資料夾

└── _js/            # jQuery 函式庫


## 🚀 使用方式

直接下載或 clone 此專案，然後用瀏覽器開啟 `demo.html` 即可。

```bash
git clone https://github.com/xd8243756/Portfolio.git
cd Portfolio
# 以瀏覽器開啟 demo.html
```

## ✨ 功能介紹

- **首頁輪播**：自動切換的作品預覽幻燈片，附有前後切換按鈕
- **關於我**：創作者個人介紹
- **作品集**：支援分類篩選（全部 / 直式 / 橫式插圖），點擊作品可查看詳細介紹
- **社群連結**：Pixiv 與 Twitter 連結

## 🛠️ 使用技術

- HTML / CSS / JavaScript
- jQuery 3.7.1
